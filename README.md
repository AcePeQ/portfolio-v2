# Personal Portfolio

A personal portfolio website built with **Next.js**, **TypeScript** and **Tailwind CSS**.

The goal of this project is to present my frontend projects, experience, skills and selected case studies in a clean and accessible way.

This is also my first project built with Next.js, created as a practical way to learn the framework after working mainly with React.

## Features

- Responsive portfolio website
- Project listing page
- About me section
- Contact section
- Reusable UI components
- Static project data
- SEO-friendly structure
- Optimized images with Next.js

## Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **ESLint**
